### 🩺 [Pneumonia Detection on Chest X-rays](https://github.com/abdellahessou/deeplearning)

Deep learning project that classifies chest X-rays as **NORMAL** or **PNEUMONIA** using transfer learning, with Grad-CAM to show which parts of the image drove each prediction and a **Streamlit** web app for demos.

<p align="center">
  <a href="https://github.com/abdellahessou/deeplearning">
    <img src="https://github.com/abdellahessou/deeplearning/raw/main/reports/figures/gradcam_mobilenetv2.png" alt="Grad-CAM explanations on test X-rays" width="800"/>
  </a>
</p>

**Pipeline:** `Data prep & augmentation → Transfer learning (MobileNetV2 · ResNet50 · VGG19) → Evaluation on held-out test set → Grad-CAM → Streamlit app`

**Highlights**
- Optimised for **recall** (missing a sick patient is worse than a false alarm): **98.7% recall, 0.96 AUC** on 624 test images
- Compared three architectures and picked **MobileNetV2**: as accurate as the others, ~10× lighter and ~10 ms per image on CPU
- Honest evaluation: documented why validation scores overstate performance and reported test-set results only
